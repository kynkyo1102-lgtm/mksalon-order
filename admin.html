PLACE DE NINA / DATA ADMIN

月度・商品・お知らせ管理

この管理画面は mksalon-order 専用です。編集後はJSONをダウンロードし、同じ名前でGitHubの mksalon-order にアップロードしてください。自動公開はしません。

データを読み込んでいます…

1. 月度設定

1件は必須、最大2件。月度を切り替えても、ほかの月度のポイント・価格設定は保持します。

2. 商品・ポイント設定

基本価格は全月度共通。月度別価格が必要な商品だけ「個別価格」をオンにしてください。ポイントは月度ごとに入力します。

3. お知らせ管理

上から新しい順に並べてください。最初の1件がトップページにNEW表示されます。日付は表示用文字列です。

4. JSONの読み込み・書き出し

初回は公開中のデータを自動で読み込みます。手元のJSONを読み込むこともできます。保存先は mksalon-order のルートです。

出力名：month_config.json / news.json。価格の個別設定は prices に記録されます。月度別価格を利用する前に注文・計算ツール側の対応が必要です。
